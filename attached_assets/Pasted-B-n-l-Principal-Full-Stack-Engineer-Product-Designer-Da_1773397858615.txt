6. API V2 BẮT BUỘC
==================================================
Tạo API v2 đầy đủ kiểu SMM panel chuẩn:

Endpoint duy nhất hoặc RESTful, nhưng phải hỗ trợ logic tương đương:
- action=services
- action=add
- action=status
- action=multiple_status
- action=balance
- action=refill
- action=refill_status
- action=cancel

Hoặc REST tương đương:
- POST /api/v2/order
- GET /api/v2/services
- GET /api/v2/order/:id
- POST /api/v2/order/status/bulk
- GET /api/v2/balance
- POST /api/v2/refill
- GET /api/v2/refill/:id
- POST /api/v2/cancel

Phải có:
- API auth bằng API key
- rate limit
- request logs
- response chuẩn JSON
- error codes rõ ràng
- docs chi tiết
- ví dụ request/response
- support bulk status
- logs cho admin

11. RLS / PERMISSIONS / SECURITY
==================================================
Phải viết đầy đủ bảo mật:
- RLS policies cho tất cả bảng
- user chỉ xem dữ liệu của mình
- admin role có quyền rộng
- API key không lộ
- provider API key không lộ ra client
- không để secret trên frontend
- dùng server/edge function hoặc backend proxy cho các thao tác provider nhạy cảm
- validate toàn bộ input bằng zod
- rate limit API
- audit logs cho thao tác admin quan trọng
- transaction integrity khi tạo order/trừ balance
- chống race condition khi order
- idempotency basic cho API nếu cần
- logs lỗi rõ ràng
- webhook verification nếu có
