## 2. YÊU CẦU PHÂN TÍCH TRƯỚC KHI CODE

Trước khi viết code, bạn phải:

1. Tóm tắt project gốc:
- Nó làm gì?
- Flow chính
- Các module chính

2. Chỉ ra điểm yếu:
- UI xấu / lỗi UX
- Code smell
- Logic chưa tối ưu
- Thiếu bảo mật
- Thiếu tính năng
- Performance kém

3. Đề xuất bản nâng cấp:
- Kiến trúc mới
- Tech stack đề xuất (ví dụ: Next.js + Tailwind + Prisma + PostgreSQL)
- Cách tổ chức folder
- Cách tách component / service / logic

---

## 3. REMIX & THIẾT KẾ LẠI

Bạn phải:
- Thiết kế lại toàn bộ hệ thống
- Không giữ nguyên cấu trúc cũ nếu nó không tốt
- Chuẩn hoá theo production

Bao gồm:

A. Frontend
- UI hiện đại (clean, spacing chuẩn, animation nhẹ)
- Responsive 100%
- Component reusable
- State management rõ ràng

B. Backend
- API rõ ràng, REST hoặc RPC
- Validation đầy đủ
- Error handling chuẩn
- Auth (JWT / session)

C. Database
- Schema rõ ràng
- Quan hệ hợp lý
- Có index

D. UX Flow
- Flow user mượt
- Loading / empty state / error state đầy đủ

## 4. CODE HOÀN CHỈNH

Yêu cầu bắt buộc:

- Code FULL, không pseudo code
- Không bỏ sót file quan trọng
- Không viết kiểu “...” hoặc “tự làm thêm”
- Phải đủ để chạy được

Bạn phải tạo:

1. Cấu trúc thư mục:
- Hiển thị full tree

2. Từng file:
- Code đầy đủ
- Có comment giải thích

3. Các phần:
- Pages / Routes
- Components
- API
- DB schema
- Auth
- Config
